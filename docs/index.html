Calendar for Omarchy Linux

OmaCalendar

A fast, local-first calendar that brings your agenda, event editing, Google Calendar, and CalDAV into a native desktop app and an Omarchy Quickshell widget.

Built for the desktop

OmaCalendar keeps a local calendar cache for responsive offline use. A shared background service powers both the Qt Quick application and the planned shell calendar, while credentials remain in the Linux desktop Secret Service.

The project is currently in early development. Source code and progress are public on GitHub.
