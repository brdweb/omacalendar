# Keyboard shortcuts

Press **?** in the app to see this list. Single-key shortcuts (such as T or Q)
work when no text field, editor or settings panel has focus.

## General

| Keys | Action |
|---|---|
| Ctrl+N | New event |
| Q, Ctrl+Shift+N | Quick add |
| Ctrl+F, / | Search |
| Ctrl+Shift+T | Show or hide tasks |
| Ctrl+P | Print or save as PDF |
| Ctrl+O | Import an iCalendar file |
| Ctrl+R, F5 | Sync now |
| Ctrl+, | Settings |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| ? | Keyboard shortcuts |
| Ctrl+Q | Quit |

## Views

| Keys | Action |
|---|---|
| Alt+1 … Alt+5 | Agenda, day, week, month, year |
| T | Go to today |
| [, ] | Previous or next period |
| Left, Right | Previous or next day |

## Events

| Keys | Action |
|---|---|
| Up, Down | Select the previous or next event |
| Enter | Open the selected event |
| Delete | Delete the selected event |
| Alt+Up, Alt+Down | Move the selected event 15 minutes |
| Alt+Shift+Up, Alt+Shift+Down | Change the selected event's end by 15 minutes |
| Alt+Left, Alt+Right | Move the selected event a day |

## Editors

| Keys | Action |
|---|---|
| Ctrl+Enter, Ctrl+S | Save |
| Escape | Close, asking first if there are unsaved changes |

## Date and time fields

| Keys | Action |
|---|---|
| Alt+Down | Open the date picker |
| Arrow keys, Page Up, Page Down, Home | Move the picker by day, week, month, or to today |
| Enter, Space | Pick the date |
| Escape | Close the picker |
