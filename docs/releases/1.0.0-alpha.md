## Known limitations

- This alpha is not production-supported and must not be the sole copy of
  calendar data.
- Complete Google write, Nextcloud, Fastmail, authenticated ICS, and remaining
  Radicale acceptance matrices are deferred to stable 1.0.
- Complete all-view desktop accessibility/offline testing remains a stable 1.0
  app gate. The optional widget has its own independent acceptance matrix.
- Source and binary AUR publication is deferred until the stable clean-chroot
  package gate passes.
- Other Linux distributions, architectures, Microsoft/Exchange, mobile
  platforms, macOS, and Windows are outside the alpha support boundary.
