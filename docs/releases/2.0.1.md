# OmaCalendar 2.0.1

A companion-widget update. The built-in widget installer moves from widget
0.1.0 to 0.2.0. No IPC, schema, or feature change in the app.

## Candidate identity

App 2.0.1; IPC 2.2; schema 3; current x86-64 Arch/Omarchy. The companion
widget is released independently: widget 0.2.0 (signed tag `v0.2.0` at
`ba25189`, published 2026-09-30) is qualified with app 2.0.0 over IPC 2.2.
Candidate source: PR #75. The signed tag, release run and package hash are
recorded under "Post-tag draft gates" once they exist.

The owner directed this release on 2026-09-30. Gates marked `WAIVED` below
were consciously skipped, not run; the evidence column states exactly what did
run for each. See [RELEASE.md](../RELEASE.md) for the waiver rule.

## Changed behavior

- `AppController::installWidget` (the desktop app's widget install action) and
  `omacalendar-widgetctl` pin widget tag `v0.2.0` and its commit
  `ba251899695f880b4750e1309f38d522a1b86aeb`, replacing `v0.1.0`. widgetctl
  refuses any other ref and checks that the cloned tag resolves to that commit.
- An existing widget install is left as it is. widgetctl has no in-place
  upgrade: moving to 0.2.0 is restore, then install, then
  `omarchy restart shell`, because the shell's plugin hot reload can keep the
  previous widget's QML.

## Interface and data

No IPC, schema, packaging, or configuration change. `docs/IPC.md` is
unchanged.
