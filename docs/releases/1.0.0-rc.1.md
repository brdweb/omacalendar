## Known limitations

- Pending owner checks include all five views, dense-calendar drag/resize,
  accessibility, real widget bar edges, mixed-scale monitors, and native
  systemd activation on a clean Omarchy desktop.
- Live Google, complete Radicale, Nextcloud, Fastmail, and authenticated ICS
  acceptance remain distinct from deterministic provider tests.
- Flatpak has separate data and keyring identities. The native widget uses
  the native app/daemon; it does not connect to the Flatpak profile.
- Candidate packages must not be the only copy of important calendar data.
- The GitHub Flatpak bundle is not a Flathub listing or an automatic-update
  repository. AUR publication and widget marketplace approval are independent.
