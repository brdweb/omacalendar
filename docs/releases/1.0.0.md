# OmaCalendar 1.0.0

The first stable release for current x86-64 Arch/Omarchy, with a local calendar
cache, five calendar views, Google Calendar and CalDAV, ICS subscriptions,
calendar sets, recurring events, invitations and reminders.

This release includes fixes from desktop testing: complete mini-calendar event
indicators, visible calendar-set ordering, persistent sidebar visibility,
silent initial invitation import, read-only widget details and app activation.

Install the native Arch package using [the installation guide](../../INSTALL.md).
The optional widget is independently released as 0.1.0.

## Candidate identity

App 1.0.0; IPC 2.0; schema 2; current x86-64 Arch/Omarchy.
The signed tag identifies the exact source; GitHub attestations identify the
final package. The maintainer approved public stable publication on 2026-09-09
following hands-on calendar testing and resolution of reported issues.

## Known limitations

- Native x86-64 Arch/Omarchy is the supported binary distribution.
- CalDAV scheduling varies by server; this-and-future RSVP is disabled.
- ICS subscriptions are read only. The built-in local calendar can be hidden.
- No Exchange, mobile app or hosted calendar service is included.
- See [support scope](../../SUPPORT.md) and [privacy](../PRIVACY.md).
