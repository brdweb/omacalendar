# OmaCalendar 2.0.0

A feature release. It adds tasks, guests' availability, undo, printing and a
reworked desktop UI, and speeds up the daemon on large calendars. See the
[changelog](../../CHANGELOG.md#200---2026-09-29) for the full list.

## Candidate identity

App 2.0.0; IPC 2.2; schema 3; current x86-64 Arch/Omarchy. The companion
widget is released independently and keeps working against IPC 2.2. Candidate
source: the merge commit of the 2.0.0 release-preparation PR, on top of
`abf6875` (PR #72). The signed tag, release run and package hash are recorded
under "Post-tag draft gates" once they exist.

The owner fast-tracked this release on 2026-09-29. Gates marked `WAIVED` below
were consciously skipped, not run; the evidence column states exactly what did
run for each. See [RELEASE.md](../RELEASE.md) for the waiver rule.

## Interface and data

- IPC 2.2 is additive over 2.1: `settings.getMany`, `stats.dailyCounts`,
  `contacts.suggest`, `freebusy.query`, `sync.setInteractive`,
  `taskLists.*` and `tasks.*`, the `events.search` `attendee` parameter,
  `events.get` `attachments`, `addConference` on event writes, and the
  `events.freeBusy` and `tasks.changed` notifications. `system.info` reports
  `protocolMinor: 2`. See [IPC.md](../IPC.md).
- The database moves from schema 2 to 3 on first open (bounded historical
  series, exception indexes, read-performance indexes). The task tables are
  added by an idempotent step within schema 3. The migration is one-way: a
  1.1.x daemon refuses a schema-3 database.
- Google OAuth scope version 4: the app also requests
  `https://www.googleapis.com/auth/calendar.freebusy` and
  `https://www.googleapis.com/auth/tasks`, so connected Google accounts
  reauthorize once.

## Known limitations

- Google Tasks writes are last-write-wins: the Tasks API has no conditional
  writes, so an edit made elsewhere between two syncs can be overwritten.
  CalDAV to-dos use ETags and merge concurrent changes.
- A Google task create whose response was lost is matched to an identical
  task on Google before it is retried. A task added elsewhere with identical
  content in that window is taken as the same task.
- Google Tasks stores only a due day; a due time set in OmaCalendar is dropped
  on a Google list.
- Moving a task between lists is not supported yet.
- Guests' availability is looked up through Google only. CalDAV scheduling
  free/busy (RFC 6638) is not implemented, so those guests show as "Can't
  check".
- All limitations from [1.1.1](1.1.1.md) continue to apply.
