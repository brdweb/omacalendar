## Paired candidate replacement

App `1.0.0-rc.3` and widget `0.1.0-rc.3` supersede RC2 after verification
of the actual downloaded artifacts found two packaging-integrity defects:

- The RC2 Flatpak SPDX described 61 locale files from the pre-export build
  stage that were not present in the distributed bundle. Flatpak's separate
  locale export caused this mismatch; a valid attestation did not make the
  staged inventory an exact bundle inventory.
- GitHub normalized the RC2 Debian asset filename's `~` to `.`, so its
  actual download name did not match the immutable checksum/install examples.
  Package bytes and the internal Debian version were unchanged.

RC3 corrects the Flatpak export/SBOM boundary and verifies the exact bundled
regular-file inventory. It uses the GitHub-safe Debian asset name
`omacalendar_1.0.0-rc.3-1_amd64.deb` while keeping the internal package version
`1.0.0~rc.3-1`. Its metadata, hashes, and published asset names require fresh
downloaded-artifact verification; these corrections are not evidence of a pass.

Prior tags, any existing draft artifacts, and historical acceptance records
remain unchanged. RC1's widget tagger-email issue and RC2's package-integrity findings
are retained as history. Do not retag, overwrite old assets, or transfer prior
acceptance claims to RC3. App/widget runtime logic, IPC, schema, and every
pending owner acceptance gate are unchanged.

## Known limitations

- Pending owner checks include all five views, dense-calendar drag/resize,
  accessibility, real widget bar edges, mixed-scale monitors, and native
  systemd activation on a clean Omarchy desktop.
- Live Google, complete Radicale, Nextcloud, Fastmail, and authenticated ICS
  acceptance remain distinct from deterministic provider tests.
- Flatpak has separate data and keyring identities. The native widget uses
  the native app/daemon; it does not connect to the Flatpak profile.
- Candidate packages must not be the only copy of important calendar data.
- The GitHub Flatpak bundle is not a Flathub listing or an automatic-update
  repository. AUR publication and widget marketplace approval are independent.
