# OmaCalendar 2.1.0

A feature and hardening release: clearer errors and account setup, date and
time entry, per-event colours, default reminders, copy and paste, view
preferences, backup, translations, a friendlier CLI, Outlook/Exchange and
Google recurrence fixes, reminder fixes, and a sandboxed background service.
It moves the local IPC to 2.3 (additive) and the database to schema 4.

## Candidate identity

App 2.1.0; IPC 2.3; schema 4; current x86-64 Arch/Omarchy. The companion
widget pin is unchanged: widget 0.2.0 (signed tag `v0.2.0` at `ba25189`).
Runtime source: PENDING (the release-prep commit on `main`).

## Changed behavior

- The database migrates from schema 3 to 4 on first open (adds
  `events.color` and an index on `reminder_jobs(event_id)`). The migration is
  one-way; a 2.0.x daemon refuses a schema-4 database.
- New ICS subscriptions start with alerts muted.
- The user service runs with `SystemCallFilter=@system-service`,
  `MemoryDenyWriteExecute` and `ProtectSystem=full`.
- CalDAV requests have a 120 s overall limit, Google API requests use a
  same-origin redirect policy, interactive Google sign-in times out after 10
  minutes, and IPC clients with more than 8 MiB of unread output are
  disconnected.
- See CHANGELOG.md for the complete list.

## Interface and data

IPC 2.3 (additive): `system.backup`; event `color`; `privateNetwork` in
`accounts.addIcs` and `ics.status`; error codes `authorization_timeout`,
`private_network_redirect_blocked` and transport codes (`host_not_found`,
`tls_error`, `timeout`, `network_unavailable`, `connection_refused`). New
free-form settings keys are documented in `docs/IPC.md`. Installed files add
the `omacalendarctl` man page and bash, zsh and fish completions.

## Known limitations

- All limitations from [2.0.2](2.0.2.md), [2.0.1](2.0.1.md) and
  [2.0.0](2.0.0.md) continue to apply.
- The schema 3 to 4 migration is one-way.
- `ProtectSystem=strict` and `ProtectHome` are not used, because the service
  writes exports to the location the user chooses.
- English is the only translation; other languages can now be added.
- The year view and sidebar mini month take their first day of the week from
  the system locale rather than the preference.
- Hidden weekends do not apply to the PDF month layout.
