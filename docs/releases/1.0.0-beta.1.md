## Known limitations

- The beta is a public testing release, not the only supported copy of important
  device-only calendar data. Keep provider and local backups.
- Current stable Omarchy on x86-64 is the only release target.
- Microsoft/Exchange, mobile, macOS, Windows, tasks, hosted scheduling, and
  remote calendar creation are outside the 1.0 product boundary.
- The widget has an independent version, release record, and marketplace
  review. Widget availability does not imply matching app version numbers.
- Provider behaviors not completed in the recorded beta matrix remain
  unsupported rather than silently falling back to destructive behavior.
- Remaining hands-on desktop navigation, accessibility, multi-monitor/mixed-scale
  widget behavior, shell reload, real-bar install/update/removal, application
  focus, and daemon-on-demand checks are unverified on the exact final build.
- The full real-Google write/invitation/token-reuse/restart matrix and other
  unrecorded provider scenarios are unverified. Google approval is complete;
  external login and sync were confirmed by the owner.
- Native package installation/removal is qualified in clean current Arch;
  the matching archive runtime is checked on current Omarchy. Direct installation
  of the final native package into the owner's host and host systemd socket
  activation are unverified; host privilege restrictions were not bypassed.
- The owner explicitly accepted these testing gaps for this first public beta
  on 2026-09-07. They are not passing test results and do not waive stable 1.0
  acceptance, artifact verification, or critical/high defect gates.
