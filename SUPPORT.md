# Support

OmaCalendar 1.0 supports current x86-64 Arch/Omarchy using the native Arch
package. Google Calendar, local calendars, CalDAV and read-only ICS feeds
are available. Radicale and Nextcloud have automated integration coverage;
other CalDAV servers may differ in recurrence and scheduling behavior.

Report bugs in [GitHub issues](https://github.com/brdweb/omacalendar/issues).
Include the app/widget version, Arch/Omarchy version, affected provider,
reproduction steps and expected behavior. Remove personal event content,
account addresses, calendar URLs, passwords and tokens from attachments.

CalDAV this-and-future RSVP is unavailable; occurrence and series responses
require scheduling support from the server. Microsoft/Exchange integration,
mobile platforms, macOS, Windows, tasks and hosted scheduling are outside
this release's scope. Community support has no response-time guarantee.

For security issues, use [private vulnerability reporting](SECURITY.md).
See [compatibility](docs/COMPATIBILITY.md) and [recovery](docs/BACKUP_AND_RECOVERY.md).
